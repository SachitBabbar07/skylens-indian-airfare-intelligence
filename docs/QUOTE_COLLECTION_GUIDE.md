# Entering authentic quotes

Start with [source access](../reports/quote_source_access_audit.md), [sampling plan](../reports/quote_collection_plan.md) and [schema](../reports/quote_collection_schema.md). The template is empty on purpose. Do not type a plausible example price or copy an airline page until collection/storage permission is established. A personal booking account does not grant research reuse.

1. Obtain a source-specific permission/license covering the intended collection method and retained evidence. Have a reviewer record its terms, collection period, retention deadline, permitted daily limit, no-cost status and whether ML is allowed. Do not enable paid APIs. Store the authentic permission document under `data/quotes/evidence_incoming/`, which Git ignores.
2. Copy `config/quote_permissions.example.json` to `data/quotes/permissions.json`. Add actual source grants using the `source_grant` definition in `config/quote_schema.json`. No grant example with invented rights is supplied. Use a public HTTPS terms URL without query/session/auth tokens and the document's actual SHA-256. Compute a hash with `Get-FileHash -Algorithm SHA256 -LiteralPath <path>`.
3. Copy `config/quote_template.csv` to `data/quotes/incoming.csv`. In Excel or a CSV editor, keep IDs, dates and amounts as text to avoid automatic date/rounding changes. Save UTF-8 CSV. One row is one actual offered itinerary at one collection instant. JSON columns are `passenger_composition`, `itinerary_segments`, `semantic_evidence`, `original_values`; a CSV editor must quote embedded JSON correctly. Column definitions are in the schema report.
4. Record only values shown by the authorized source. Leave missing cells blank; use `unknown` for explicit status enums. Mandatory fields include quote/source IDs/name/URL/terms, collection UTC, airport endpoints and departure date. Use ISO dates `YYYY-MM-DD` and offset-aware timestamps. A selectable all-in single-adult INR price needs evidence for each semantic gate before it can be labeled verified. If final mandatory fees depend on payment method and are not shown, fees remain unknown. Do not proceed to payment just to complete this project.
5. Retain permitted, redacted evidence showing the search parameters, complete itinerary, currency, passenger basis, tax/fee scope and displayed total. Include return legs in the **same** return offer. Remove names, PNRs, account/contact data, cookies, access tokens and payment details before hashing. Evidence filenames are private local relative paths. A reviewer records their ID, actual review time, and field-to-page/section locations. No unlicensed screenshot is required or authorized by this guide.
6. From the project root, validate first. Review the returned counts and private batch field-level errors after ingestion. A research-only row is not a training target. Resolve source/schema issues in a new CSV version without changing an old raw file.

```powershell
$env:PYTHONPATH = 'src'
.\.venv\Scripts\python.exe -m skylens.quotes validate --input data/quotes/incoming.csv --permissions data/quotes/permissions.json
.\.venv\Scripts\python.exe -m skylens.quotes ingest --input data/quotes/incoming.csv --permissions data/quotes/permissions.json
.\.venv\Scripts\python.exe -m skylens.quotes summary
```

`validate` does not archive the CSV. The CLI may create the ignored store/lock and an error-type log; it never sends a network request. `ingest` archives authorized input/evidence and prints provisional counts. `summary` is the conflict/deduplication-aware count. Never equate raw-row counts with independent itineraries or collection dates. Stop collection at a source's limit, changed terms, expired/revoked permission or any access restriction. This importer is not a license checker or API quota monitor for an external collector.

For a future approved experiment, preregister three collection-time boundaries separating training, validation, calibration and test. Run `freeze-split --boundary <UTC validation start> --boundary <UTC calibration start> --boundary <UTC test start> --output data/quotes/splits/<version>.json`. Shared flight segments connect records across carriers/classes/journey types; components crossing a boundary are purged. Different source snapshots of a shared itinerary cannot leak through a source split. The manifest records dataset hash and IDs only. It cannot overwrite different content. Empty partitions are not ready. A structural split never proves sufficient sample size; follow the statistical plan and keep the final test sealed from tuning.

No new source is currently approved and no genuine quote has been collected. This workflow is ready for a lawful source or an authentic licensed user-supplied file. The existing API continues to serve its original historical research estimates only.
